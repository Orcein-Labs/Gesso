# Harpe stack vision — archived 2026-10

`harpe-stack.md` is the predecessor vision for this runtime, written while the
project was still called Harpe. It describes an ML stack built around a
semantic operator layer, with checkpoint formats treated as transport and
execution semantics kept separate.

What survives into current canon: the checkpoint-transport principle and the
"ordinary models first, exotic models after" order.

What replaced it: `docs/Gesso_Stack.md`, which wins wherever the two disagree.
